# My Future Pet: Android app downloads

This repository only hosts the Android app (APK) for **My Future Pet**, the pet adoption app for the
Jagna Animal Lover and Rescue Group (JALRG), Jagna, Bohol.

**Download the latest version:** https://github.com/kofyxx/myfuturepet-app/releases/latest/download/MyFuturePet.apk

Or visit https://myfuturepet.net.

New versions install over the old one; your account and saved pets stay.
